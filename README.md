# Biofy: Your Page, Your Style

Crie o Biofy, uma plataforma SaaS completa de criação de páginas personalizadas para bio, semelhante ao conceito do Linktree, porém com uma experiência muito mais moderna, visual, interativa e personalizável.

O Biofy permite que qualquer pessoa crie sua própria página pública personalizada, reúna seus links e compartilhe um único endereço na bio do Instagram, TikTok, YouTube etc.

A aplicação deve ser REALMENTE FUNCIONAL.

Não quero apenas uma landing page ou protótipo visual.

O usuário deve conseguir criar uma conta, escolher seu username, criar sua página, personalizá-la através de um editor visual, salvar, publicar e acessar sua página através de uma URL própria.
